## Frameworks and Libraries
- [PennyLane](https://pennylane.ai/) - A cross-platform Python library for differentiable programming of quantum computers.
- [Qiskit Machine Learning](https://qiskit.org/ecosystem/machine-learning/) - Contains QML algorithms, neural networks, and PyTorch connectors.
- [TensorFlow Quantum](https://www.tensorflow.org/quantum) - A quantum machine learning library for rapid prototyping of hybrid quantum-classical ML models.
- [Yao.jl](https://yaoquantum.org/) - Extensible, Efficient Quantum Algorithm Design for Humans (Julia).

## Algorithms
- **Quantum Support Vector Machine (QSVM)**: Maps data to a quantum feature space to find the optimal hyperplane.
- **Quantum Neural Networks (QNN)**: Parameterized quantum circuits used as neural network layers.
- **Quantum Generative Adversarial Networks (QGAN)**: Generative models trained on quantum processors.
